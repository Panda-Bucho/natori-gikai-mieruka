# 一般質問 要約プロンプト v2(全議員共通・変更禁止)

以下は名取市議会の一般質問の会議録(1人の議員の質問と行政側の答弁の一連)です。
冒頭のヘッダーの「通告テーマ」に、この質問のテーマが「 / 」区切りで書かれています。
この質疑を**通告テーマごとに分けて**、テーマごとに次の2つを作成してください。

## 出力形式

```json
{
  "topics": [
    {
      "title": "通告テーマ名",
      "summary": "このテーマの質疑の要約(150〜250字)",
      "gains": ["このテーマの答弁で示された内容(2〜4点、各80字以内)"]
    }
  ]
}
```

## テーマの分け方

- `topics` はヘッダーの通告テーマと同じ数・同じ順で作り、`title` はヘッダーの表記をそのまま使う
- 会議録の「大項目」の区切りがヘッダーの通告テーマと食い違う場合(ヘッダーにない大項目がある等)は、会議録の大項目に合わせて分け、`title` は会議録の大項目名を使う
- 一括で質問・答弁している場合や再質問も、発言の内容に応じて該当するテーマに振り分ける
- 1つの発言が複数テーマにまたがる場合は、最も関係の深い1テーマにだけ書く(同じ内容を複数のテーマに重ねて書かない)
- 時間切れ等で、会議録上そのテーマの質疑が行われていない場合は、`summary` を「会議録上、このテーマの質疑は確認できない。」とし、`gains` は空配列にする
- 冒頭の前置き(「通告に従い質問します」等)や締めのあいさつは書かない

## summary(テーマごとの要約)の書き方

- そのテーマについて、議員が何を問題提起・提案し、行政側(市長・教育長・担当部課長等)がどう答えたかの骨子を書く
- 他のテーマの内容を含めない
- 質問者の主張と行政の答弁を明確に区別する。議員は「議員は」と書き、氏名は書かない
- 数値・年度・固有名詞は会議録の表記に忠実に。会議録にない内容を推測で書かない
- 簡潔な常体(〜した。〜と答えた。)で書く

## gains(テーマごとの「質疑で得られたもの」)の書き方

- 答弁にある事実のみを根拠に、中立・事実ベースで書く。評価・採点・称賛・批判をしない
- 次の優先順で拾う:
  1. 実施の約束(「◯◯を実施すると答弁」)
  2. 時期の明示(「令和◯年度までに◯◯と表明」)
  3. 検討・研究の表明(「◯◯を検討すると回答」)
  4. 方針・スタンスの表明(「市は◯◯の立場を示した」)
  5. 現状・実績の説明(「市は◯◯の現状を説明」)
- 明確な約束がないテーマでも、答弁で示された現状説明や見解を必ず2点以上書く(質疑が行われていない場合を除き、空にしない)
- 各項目の主語を明確に(「市長は」「教育長は」「市は」)
- 「休憩」「再開」など議事進行に関する記述は無視する
